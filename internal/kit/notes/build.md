# Notes for the Proviso skills

The commands that build this system, run its unit tests and run its
acceptance tests, in the order integration runs them, and what it must
watch, such as skips that are expected; acceptance runs them too.
Proviso's command, if it is not `proviso` from the path. Whether
acceptance goes through a pull request, as a line
`Acceptance: pull request`; without one, it merges directly. The
convention for commit messages, if it is not Conventional Commits with
`docs(spec):` for edits of the spec tree. Decisions
about the system belong in the spec tree, not here.

# Glossary

## <a id="upkeep.identifier-home"></a> identifier home

- Definition: Where an element stands, as the first segment of an
  identifier names it: the identifier of the capability whose folder
  holds the element's file, or `system` for an element in a file of the
  system level.
- Contact: Bruno Baketarić
- Status: defined

## <a id="upkeep.identifier-mention"></a> identifier mention

- Definition: A code span whose whole content is an identifier, in a
  file of the spec tree, outside a rule block and outside a fenced
  block, such as `lint.tree-layout` in an Examples cell. It may refer to
  the element or be data; only a person can tell.
- Contact: Bruno Baketarić
- Status: defined
- Aliases: identifier mentions
